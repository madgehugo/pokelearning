# @pokelearning/web (phase 3)

Placeholder for the browser UI: React + TypeScript + Vite, with a responsive
layout so it also works on a phone. It connects to the server's WebSocket and
shows the live German line, its translation, a word-by-word breakdown, the word
bank and FSRS reviews.

Not part of the npm workspaces yet. Add `"apps/web"` to the root
`package.json` workspaces when scaffolding it (`npm create vite@latest`).
